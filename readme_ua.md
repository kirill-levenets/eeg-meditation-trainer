# EEG Тренажер Медитації

Мобільний додаток для тренування медитації Шаматха з використанням ЕЕГ-нейрозворотного зв'язку. Побудований на Python/Kivy для Android.

## Можливості

- **Візуалізація ЕЕГ в реальному часі** — Графік із прокруткою з єдиним масштабуванням осі Y для всіх метрик, сітка, мітки значень у реальному часі на кінцях ліній, мітки часу на осі X, пунктирна лінія порогу медитації, вирівнювання даних праворуч під час заповнення
- **Вкладка сирих ЕЕГ-даних** — Осцилюючий ЕЕГ-сигнал (128Гц субдискретизація, біполярне відображення плюс-мінус мкВ) + графіки частотних діапазонів з адаптивним масштабуванням осі Y до видимого діапазону значень
- **Графіки з прокруткою** — Усі графіки підтримують прокрутку по часу через 5-хвилинне вікно даних за допомогою слайдера або дотику/свайпу; посегментне рендерення ліній для запобігання GPU-артефактів; вертикальна + горизонтальна сітка вирівняна з мітками часу
- **Оцінка медитації** — Класична ЕЕГ-формула медитації з sqrt-нормалізованими відносними одиницями діапазонів; Спокій, оцінка Шаматха, Відволікання, Занурення та Тонке Відволікання (дисперсія короткого вікна з захистом розігріву); нативні NeuroSky eSense Attention та Meditation відображаються на графіку та зберігаються в БД/CSV
- **Багатоканальний аудіо-рушій** — Канал 1: безперервний білий шум через кросфейд WAV + Kivy SoundLoader (гучність масштабується з медитацією); Канал 2: синтезований дзвіночок тінгша для сповіщень занурення (800Гц, затухаючі гармоніки); Канал 3: м'який дзвін для тонкого відволікання (1200Гц, ефект мерехтіння); Канал 4: різкий подвійний варбл для сповіщення відключення пристрою (600/900Гц чергування). Усі з кулдауном/дебаунсом
- **Таймер медитації** — Налаштовувана тривалість (1-120 хв) з кнопками пресетів, перемикач увімкнення/вимкнення, зворотній відлік, автозупинка по завершенню, діалог вибору файлу для кастомного звуку завершення з кнопкою тесту
- **Класифікація станів** — Стабільний Фокус, Тонке Відволікання, Грубе Відволікання, Занурення
- **NeuroSky MindWave Mobile 2** — Підтримка реального ЕЕГ-пристрою через Bluetooth Classic RFCOMM на Android (pyjnius) та десктопному Linux (Python socket BTPROTO_RFCOMM); парсер протоколу ThinkGear витягує 8 діапазонів потужності, увагу, медитацію, якість сигналу, сиру хвилю (512Гц); фоновий потік читання з автоперепідключенням; сканування спарених пристроїв через bluetoothctl; очікування BT-з'єднання при Старті (показує статус Підключення..., чекає першу дату, грає звук підключення, виявляє відключення під час сесії)
- **Панель налаштувань** — Статус/мета пристрою, перемикач mock/реальний пристрій, BT-сканування + вибір зі списку спарених, слайдер порогу (20-100), кнопка тесту аудіо, перемикач сповіщення занурення, перемикач сповіщення відключення, перемикачі метрик графіка, слайдер товщини лінії (0.5-4.0), кнопка повороту екрану (0/90/180/270), поле кастомної формули; все зберігається для кожного користувача
- **Кастомна формула** — Метрика визначена користувачем через Python-подібний вираз з використанням потужностей діапазонів (alpha1, alpha2, beta1, beta2, gamma1, gamma2, theta, delta), комбінованих діапазонів (alpha, beta, gamma), нормалізованих діапазонів (alpha_norm та ін.), обчислених метрик (meditation_score, shamatha_score, distraction, sinking та ін.), математичних функцій (sqrt, abs, log, exp, pow, min, max, sin, cos, tanh) та віконного середнього `avg(expr, N)` для згладженого ковзного середнього за N точок по будь-якому виразу (макс 600 точок); AST-парсинг з валідацією білого списку, захист від ділення на нуль та переповнення; відображається як пурпурна лінія на графіку; зберігається для кожного користувача
- **Щоденник сесій** — Нотатки, теги, оцінка настрою, CSV-експорт, видалення (з діалогом підтвердження) та перейменування сесій, підсвітка вибраної сесії, попередній перегляд сигналу з вкладками (Метрики / Сирий ЕЕГ / Частоти) з прокруткою + лінія порогу; статистика сесії включає тривалість, середню медитацію/шаматху, час вище порогу, найдовшу серію медитації, поріг, оцінку настрою; вкладка Сирий ЕЕГ синтезує наближену біполярну хвилю зі збережених потужностей діапазонів
- **Повне збереження сигналу** — Сирі ЕЕГ-діапазони, обчислені метрики, частоти, стабільність, спокій, нативні NeuroSky увага та медитація зберігаються потіково в SQLite
- **CSV-експорт** — Експорт повних даних сигналу будь-якої сесії (сирі + обчислені) в CSV зі щоденника
- **Симуляція Mock ЕЕГ** — Формат сумісний з NeuroSky: потужності діапазонів у діапазоні ASIC_EEG_POWER (3-байтові беззнакові цілі), сира хвиля 512Гц, eSense увага/медитація (0-100), якість сигналу; стейт-машина з плавними переходами, крос-діапазонним зв'язком, гаусовим шумом, сплесковою активністю
- **Профілі користувачів** — Вибір/створення профілю при запуску; фільтрація сесій по користувачу; останній користувач зберігається між перезапусками; щоденник прихований поки користувач не вибраний; збереження налаштувань для кожного користувача
- **Захист сесій** — Старт заблоковано якщо користувач не вибраний або якщо mock вимкнений без вибору реального BT-пристрою
- **Аналітика** — Тренди день/тиждень/місяць з мітками значень на осі Y та мітками часу на осі X, лічильник серій, відстеження прогресу, відображення використання БД
- **Відладкове логування** — Кожна дія/подія логується; сирі ЕЕГ-семпли логуються періодично під час сесії
- **SQLite-сховище** — Сесії, часові ряди метрик, профілі користувачів, налаштування по користувачу з автоматичною міграцією схеми; проміжне збереження під час сесії з оновленням фінальної статистики при зупинці

## Структура проєкту

```
app/
├── ui/                 # Kivy-екрани, віджети та ScreenManager
│   ├── app_manager.py      # Головний додаток з ScreenManager та циклом оновлення
│   ├── live_session.py      # Екран живої сесії з графіком та елементами керування
│   ├── raw_eeg_screen.py    # Вкладка сирих ЕЕГ з під-діапазонами та частотними графіками
│   ├── profile_screen.py    # Управління профілями користувачів
│   ├── settings_screen.py   # Поріг, аудіо, інформація про пристрій, перемикачі
│   ├── timer_screen.py      # Таймер медитації зі зворотнім відліком та пресетами
│   ├── diary_screen.py      # Список сесій, нотатки, настрій, CSV-експорт
│   └── analytics_screen.py  # Графіки трендів та зведена статистика
├── eeg/                # Джерело ЕЕГ-даних
│   ├── mock_stream.py       # Оригінальний симульований ЕЕГ (v1)
│   ├── mock_stream_v2.py    # Частотний синтез (v2, активний)
│   └── buffer.py            # Буфери ковзного середнього та дисперсії
├── metrics/            # Обробка сигналу та формули станів
│   ├── engine.py            # Повний пайплайн метрик з сигмоїдною нормалізацією
│   └── custom_formula.py    # Безпечний обчислювач кастомних формул (AST)
├── audio_feedback/     # Двоканальний аудіо-рушій
│   └── noise.py             # Білий шум + дзвін занурення через audiostream
├── session/            # Життєвий цикл сесії
│   └── manager.py           # Стейт-машина Старт/Пауза/Продовження/Стоп
├── storage/            # База даних
│   └── database.py          # SQLite-схема, CRUD, профілі, CSV-експорт
├── analytics/          # Агрегація даних
│   └── aggregator.py        # Обчислення трендів день/тиждень/місяць
├── config.py           # Параметри сигмоїд, пороги, константи додатку
└── logger.py           # Централізоване логування
```

## Обчислювані метрики

| Метрика | Формула | Діапазон |
|---------|---------|----------|
| Оцінка медитації | `clamp(200 * calmness / Cmax)` | 0-200 |
| Занурення | `sigmoid((theta+delta) / (alpha+beta+1))` | 0-100 |
| Відволікання | `sigmoid((beta+gamma) / (alpha+1))` | 0-100 |
| Тонке відволікання | `sigmoid(stability / stability_max)` коли score > threshold | 0-100 |
| Оцінка Шаматха | `sigmoid(calmness*0.4 + clarity*0.3 + stability_factor*0.3)` | 0-100 |

## Встановлення (Десктопна розробка)

```bash

python3 -m venv venv
source venv/bin/activate

# Встановити залежності
pip install -r requirements.txt

# Запустити тести
python -m pytest tests/ -v

# Запустити додаток
python main.py
```

## Збірка Linux-виконуваного файлу

```bash
# Збірка одною командою (створює venv, встановлює залежності, збирає PyInstaller)
./build_linux.sh

# Результат: dist/EEG_Meditation_Trainer/EEG_Meditation_Trainer
# Дистрибуція: tar czf EEG_Meditation_Trainer_linux.tar.gz -C dist EEG_Meditation_Trainer
```

Потрібен Python 3.10+, `build-essential`, `pkg-config`.

## Збірка Android APK

```bash
# Debug-збірка (одна команда — створює venv, встановлює buildozer, збирає APK)
./build_android.sh

# Release-збірка
./build_android.sh release

# Встановити на пристрій
adb install bin/eegmeditation-*-debug.apk
```

Потрібен Python 3.10+, JDK 17, `git`, `zip`, `unzip`, `autoconf`, `libtool`, `cmake`.
Перша збірка завантажує Android SDK/NDK (~1.5 ГБ) та займає 15-30 хв.

### Системні залежності (Ubuntu/Debian)

```bash
sudo apt-get install -y build-essential git zip unzip autoconf libtool \
    pkg-config zlib1g-dev libncurses5-dev libncursesw5-dev cmake \
    libffi-dev libssl-dev automake openjdk-17-jdk
```

### Усунення неполадок

- **Версія Java**: Потрібен JDK 17. Перевірте `java -version`
- **SDK/NDK**: Buildozer завантажує автоматично. Встановіть змінні `ANDROIDSDK` та `ANDROIDNDK` якщо використовуєте наявну інсталяцію
- **Перша збірка повільна**: Завантаження SDK/NDK + компіляція займає 15-30 хвилин
- **Помилки збірки**: Запустіть `buildozer android clean` і перезберіть
- **Логи**: Перевірте `buildozer android deploy run logcat` для помилок виконання
- **Дебаг**: Перевірте `buildozer android debug deploy run logcat` для помилок виконання

## Збірка Windows-виконуваного файлу

### Передумови

- **Windows 10/11** з Python 3.10-3.12 встановленим з [python.org](https://www.python.org/downloads/)
- Переконайтесь що `python` у PATH (`python --version` повинен працювати)

### Швидка збірка (автоматична)

```bat
REM Подвійний клік або запуск з командного рядка:
build_windows.bat
```

Створює venv, встановлює залежності та збирає exe. Результат: `dist\EEG_Meditation_Trainer\`

### Ручна збірка

```bat
REM Створити venv та встановити залежності
python -m venv build_venv
build_venv\Scripts\activate.bat
pip install -r requirements_windows.txt

REM Збірка
python -m PyInstaller eeg_meditation.spec --noconfirm

REM Результат: dist\EEG_Meditation_Trainer\EEG_Meditation_Trainer.exe
```

### Дистрибуція

Заархівуйте всю папку `dist\EEG_Meditation_Trainer\`. Користувач запускає `EEG_Meditation_Trainer.exe` напряму — встановлення Python не потрібне.

### Усунення неполадок

- **Відсутні DLL**: Переконайтесь що `kivy_deps.sdl2` та `kivy_deps.glew` встановлені — spec-файл включає їхні бінарники
- **Чорний екран при запуску**: Спробуйте `console=True` в spec-файлі для перегляду помилок
- **Розташування бази даних**: `meditation.db` створюється поруч з exe при запуску

## Конфігурація

Усі параметри для налаштування знаходяться в `app/config.py`:

- **SigmoidConfig** — `k` та `midpoint` для кожної сигмоїдної нормалізації
- **MetricsConfig** — Cmax, розмір ковзного вікна, пороги за замовчуванням, ліміти
- **AppConfig** — Частота оновлення, вікно графіка, інтервал збереження, налаштування аудіо
