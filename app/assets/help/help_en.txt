## Quick Start

1. Create a profile (Settings > User Profile)
2. Turn on your MindWave headset
3. Pair it in system Bluetooth settings
4. Go to Session tab; tap the chevron on Start
   to open the duration picker (5/10/15/20 min
   or Free), then press Start
5. The app auto-detects and connects
6. Meditate! Audio feedback guides you
7. When your shamatha score holds at or above
   your threshold, the status (top right) lights
   up as a green "SHAMATHA" badge

## Connection Troubleshooting

If the device won't connect:

1. Check battery — the #1 cause of connection problems.
   Replace the AAA battery if headset connects but
   shows "not streaming". Use NiMH rechargeable (1.2V),
   ignore the red LED (calibrated for 1.5V alkaline).
   Avoid Li-ion 1.5V rechargeable batteries.
2. Check Bluetooth — enabled on phone, headset paired
3. Clean skin and sensors — wash forehead with soap,
   wipe sensor pads with alcohol pad
4. Reset pairing — remove device from BT settings,
   re-pair it (fixes most connection issues)
5. Close other BT apps — only one app can
   hold the RFCOMM connection at a time
6. Restart headset — turn off, wait 5s, turn on
7. "Connected but not streaming" — weak battery.
   BT radio works on less power than the EEG chip.
   Replace the battery.
8. Test with manufacturer's app — if it also
   can't connect, the headset may be faulty

## Sensor Contact

For good EEG signal:
- Wash skin in sensor area (forehead, earlobe)
  with soap to remove oil, sweat, and dead skin
- Wipe sensor pads with alcohol
- Press sensor firmly against dry, clean skin
- Minimize hair under the sensor
- Signal quality shown during connection
  (0 = perfect, 200 = no contact)

## Audio Feedback

Two feedback channels in Settings → Audio, each
Off / Rain / Tone / Custom (wav/mp3/ogg/flac/m4a):
- Feedback sound (below threshold): plays while you
  are below your threshold and fades out as you
  approach it. Default Rain.
- Reward sound (above threshold): silent until you
  cross the threshold, then fades in and grows the
  further above you go. Default Off.

So: quieter (or the reward swelling) = deeper. The
two cross-fade at the threshold. Set either to Off
for no sound on that side. Volume rises on a log
curve, max 0.3.

Alert sounds:
- Bell = sinking/dullness detected
- Chime = subtle distraction
- Warble = device disconnected

Configure in Audio section above

## Locked-Screen Sessions (Android)

You can start a session, lock the screen, and
EEG processing and audio feedback continue
uninterrupted. The noise channel uses Android
MediaPlayer so it survives screen lock. A
persistent notification stays visible while
the session is active. If the session stops
unexpectedly, a warble sound plays to alert you.

## App Crashes

If the app hits an unexpected error, a crash dialog
will appear with the full report already copied to
your clipboard. Please paste it into a new GitHub
issue so we can fix it.

## Data Backup

Settings → Data Backup → tap "Backup database"
to write a copy of your session history to a file.
On Android, backups go to Documents/EEGMeditation/
and are visible to file managers and Telegram's
file picker. On desktop, you choose where to save.

Tap "Restore database" to replace the current
database with a backup file. This cannot be undone
— your current sessions are replaced. The app will
exit after restoring; relaunch to see your imported
history.

## User Profiles

If you've used the app before and reinstall (or
move to a new device by restoring a backup), your
existing profiles are shown when you create a
profile. Tap an existing profile to keep using it,
or type a new name to start fresh. Names must be
unique — if you type a name that exists, you'll be
offered a "Use existing" / "Change name" choice.

## Session Program

Settings → Timer → Simple | Program toggle.
"Enable Timer" is only shown in Simple mode.

Program mode lets you build a sequence of timed
segments, each with its own formula, target level,
and end-cue sound. At each boundary a transition
chime plays and the target and audio-driver update
to the next segment's settings. The session
auto-stops when the last segment ends.

Each segment row: duration (minutes), formula
(Shamatha / Meditation / NS Attention / NS
Meditation / saved custom formula), target level,
end cue (Chime or Warble).

Add rows with "+ Add Segment". Save the whole
program by name — re-saving under the same name
overwrites it. Load and delete ask for confirmation.
The editor shows the name of the currently
loaded program. Saved programs appear in a list
you can tap to reload.

On the Session screen, the button next to Start
shows "P" in program mode. Tap it → Programs…
to quick-load a saved program; the list highlights
the currently loaded one.

During a program the graph shows each segment's
metric. The legend marks the active segment with
a bold "»"; a chime plays at each segment change
and the gong sounds at the end.

The live session graph and the diary graph both
show a stepped threshold line that follows each
segment's target.

Each segment row has a Feedback picker
(Default / Rain / Tone / Custom) — "Default"
uses the global Audio setting. The source
switches at each segment boundary.

## Custom Formulas

Settings → Custom Formula has three named slots.
Each slot has a name field, an expression input,
Apply (evaluate), and Save (to library).

The expression is a Python-style formula. Available
variables include band powers (alpha, beta, theta,
delta, gamma), normalized bands (alpha_norm etc.),
computed scores (shamatha_score, meditation_score,
distraction, sinking), and windowed avg(expr, N).

One slot drives the audio noise channel. Select it
with the [1][2][3] buttons next to the
"Custom Formula" option in Settings → Threshold.
If that slot's formula is invalid, audio falls back
to shamatha.

All three formula series share one Y-axis (0–200,
reference line at 100). Keep your formula output
in a range comparable to the other metrics so the
graph stays readable.

To assign a saved formula to a slot without opening
Settings, use the "Choose..." button on the matching
custom-formula row in the on-graph series picker
(the list icon in the top-left of the metrics graph).

The diary replays the formulas from each session —
opening a past session shows the names and series
that were active at that time.
