# Contributing

Thanks for your interest in EEG Meditation Trainer.

This project doesn't accept pull requests, patches or other code contributions. Every change goes through the maintainer's own review, testing on a phone with a real headset, and release process. Please don't post fixes, diffs or branches in issues: they won't be merged.

What helps most is an issue:

- **A bug report:** what you did, what you expected and what happened instead. Include the app version and your platform (Android, Linux, Windows or macOS). On a connection problem, **Settings → Device → Copy Diagnostics** builds a report you can paste. Remove anything personal first.
- **A feature idea:** the problem you want solved, and how you use the app when you run into it.
