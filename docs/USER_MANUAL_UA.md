# ЕЕГ Тренажер Медитації - Посібник користувача

> **Застереження:** Це програмне забезпечення призначене лише для освітніх та особистих дослідницьких цілей. Це не медичний пристрій, і його не слід використовувати для медичної діагностики чи лікування. Дані ЕЕГ із побутових гарнітур за своєю природою містять шуми. Використовуйте на власний ризик.

## Початок роботи

### Перший запуск

Після відкриття додатку ви побачите екран **Profile** (перша вкладка).
Перш ніж розпочати сесію, потрібно створити профіль користувача.

### Створення користувача

1. Введіть ваше ім'я у текстове поле
2. Натисніть **Create User**
3. Ваше ім'я з'явиться у списку - натисніть на нього, щоб зробити його активним
4. Поточний активний користувач показаний зверху: "Current: ВашеІм'я"

Можна створити кілька профілів (наприклад, для членів родини). Кожен користувач має власні сесії, налаштування та збережені формули. Натисніть на будь-яке ім'я у списку, щоб переключитися. Натисніть **Show All Users**, щоб побачити сесії всіх користувачів.

### Навігація

Панель вкладок зверху має 7 вкладок:

**Profile** | **Session** | **Raw EEG** | **Settings** | **Timer** | **Diary** | **Analytics**

Натисніть кнопку-гамбургер (**&#9776;**) зліва, щоб сховати/показати панель вкладок (корисно на малих екранах).

Вкладка **Diary** неактивна, поки не обрано користувача.

## Налаштування (Settings)

Перейдіть на вкладку **Settings**, щоб налаштувати додаток перед першою сесією.

### Пристрій

За замовчуванням додаток використовує **Mock Data** (імітовані дані ЕЕГ для тестування). Щоб використати справжній NeuroSky MindWave Mobile 2:

1. Переконайтеся, що гарнітура з'єднана з вашим пристроєм через Bluetooth
2. Зніміть галочку **Use Mock Data**
3. Натисніть **Scan Paired Devices**
4. Натисніть на ваш MindWave у списку пристроїв
5. Статус покаже "Selected: MindWave Mobile"

На Linux також можна використати прапорець командного рядка `--serial` для читання з послідовного порту.

### Поріг медитації

Повзунок порогу (20-100) встановлює рівень оцінки медитації, який використовується для:
- Пунктирної лінії на графіку сесії
- Статистики "Час вище порогу"
- Цільового значення аудіо-зворотного зв'язку

### Метрика керування аудіо

Оберіть, яка метрика керує гучністю білого шуму:
- **Meditation Score** (за замовчуванням) - основна формула шаматхи
- **Shamatha Score** - те саме, що й медитація у поточній версії
- **NS Meditation** - вбудоване значення медитації NeuroSky
- **NS Attention** - вбудоване значення уваги NeuroSky
- **Custom Formula** - ваша власна формула (якщо визначена)

### Аудіо-зворотний зв'язок

Додаток забезпечує аудіо-зворотний зв'язок у реальному часі під час сесій:

- **Білий шум** - гучність зменшується зі зростанням обраної метрики (тихіше = глибша медитація). На рівні порогу шум стихає повністю.
- **Дзвіночок погруження** - звук тінгші, коли сонливість (тета+дельта) стає занадто високою. Увімкніть/вимкніть галочкою.
- **Дзвіночок тонкого відволікання** - м'який дзвіночок, коли короткочасна варіація оцінки медитації висока (розум коливається). Увімкніть/вимкніть галочкою.
- **Сигнал від'єднання** - вібруючий звук при втраті з'єднання з гарнітурою. Увімкніть/вимкніть галочкою.

Натисніть **Test Audio**, щоб прослухати зразок.

### Відображення

- **Line Width** (0.5-4.0) - товщина ліній графіку для вашого розміру екрану
- **Rotate Screen** - циклічне обертання екрану (0/90/180/270 градусів)

### Метрики графіку

Перемикайте, які метрики показувати на графіку сесії:
- Meditation Score, Shamatha Score, Distraction, Sinking, Subtle Distraction, NS Attention, NS Meditation
- **Show Custom Formula** - відображення вашої формули як додаткової лінії на графіку

### Власна формула

Введіть математичний вираз у стилі Python для відстеження як додаткової метрики. Приклади:

```
(alpha1 + alpha2) / (beta1 + beta2 + 1)
sqrt(alpha_norm) * 100
avg(meditation_score, 20) - avg(distraction, 20)
```

Доступні змінні:
- **Сирі ритми:** `alpha1 alpha2 beta1 beta2 gamma1 gamma2 theta delta`
- **Комбіновані:** `alpha beta gamma`
- **Sqrt-відносні:** `s_alpha1 s_alpha2 s_beta1 s_beta2 s_theta s_delta`
- **Нормалізовані:** `alpha_norm beta_norm gamma_norm theta_norm delta_norm`
- **Метрики:** `meditation_score shamatha_score distraction sinking subtle_distraction stability calmness native_attention native_meditation`
- **Функції:** `sqrt abs log log10 exp pow min max sin cos tanh`
- **Ковзне середнє:** `avg(вираз, N)` - середнє за останні N тіків (N=1..600; при 2Гц: 10=5с, 60=30с)

Натисніть **Apply** для активації, **Save** для збереження. Збережені формули з'являються у списку нижче - натисніть для завантаження, X для видалення.

## Таймер (Timer)

Перейдіть на вкладку **Timer**, щоб встановити тривалість сесії.

1. Поставте галочку **Enable Timer**
2. Встановіть тривалість повзунком або натисніть пресет (5, 10, 15, 20, 30, 45, 60 хв)
3. За бажанням встановіть власний звук закінчення: натисніть **Browse** для вибору аудіо-файлу, або залиште порожнім для стандартного дзвіночка
4. Натисніть **Test Sound** для попереднього прослуховування

Коли таймер увімкнено, він запускається автоматично при початку сесії. Великий зворотний відлік показує час, що залишився. Коли він досягає 00:00, сесія зупиняється автоматично і грає звук закінчення.

## Проведення сесії (Session)

Перейдіть на вкладку **Session**.

### Старт

Натисніть **Start**. При використанні реального пристрою додаток покаже "Connecting..." до отримання даних від гарнітури. З імітованими даними сесія стартує одразу.

Заголовок показує:
- Статус пристрою (зліва) - індикатор з'єднання
- Час початку сесії та тривалість (по центру)
- Поточний стан (справа) - кольорове кодування: зелений=Стабільний фокус, жовтий=Тонке відволікання, червоний=Грубе відволікання, помаранчевий=Погруження

### Під час сесії

Графік показує метрики у реальному часі, що прокручуються зліва направо:
- **Синій** - Meditation Score (оцінка медитації)
- **Зелений** - Shamatha Score (оцінка шаматхи)
- **Червоний** - Distraction (відволікання)
- **Помаранчевий** - Sinking (погруження/сонливість)
- **Жовтий** - Subtle Distraction (тонке відволікання)
- **Фіолетовий** - NS Attention (увага NeuroSky)
- **Блакитний** - NS Meditation (медитація NeuroSky)
- **Рожевий** - Custom Formula (власна формула, якщо увімкнена)

Вісь X показує відносний час (хвилини:секунди) та реальний час доби під ним. Горизонтальні лінії сітки через кожні 20 одиниць. Пунктирна горизонтальна лінія позначає ваш поріг.

Під графіком шість блоків статистики показують поточні значення.

**Прокрутка та масштабування графіку:**
- Проведіть пальцем вліво/вправо для прокрутки історії
- Колесо миші (комп'ютер) або жест зведення/розведення пальців (Android) для збільшення/зменшення

### Маркери

Натисніть **Mark** під час сесії, щоб поставити вертикальну пурпурну лінію на графіку в поточний момент. Використовуйте для позначення подій (наприклад, "почув шум", "відволікся", "глибокий момент"). Маркери зберігаються разом із сесією і відображаються у щоденнику.

### Пауза / Продовження

Натисніть **Pause** для тимчасової зупинки запису. Кнопка зміниться на **Resume** - натисніть для продовження. Час паузи не враховується у тривалості сесії.

### Зупинка

Натисніть **Stop** для завершення сесії. З'явиться діалог із трьома варіантами:
- **Save** - зберегти всі дані сесії у базу даних
- **Discard** - видалити сесію (включно з даними, вже записаними в БД)
- **Cancel** - закрити діалог і продовжити сесію

## Сирі дані ЕЕГ (Raw EEG)

Перейдіть на вкладку **Raw EEG** під час сесії для перегляду детальних даних сигналу.

Два синхронізовані графіки:
- **Зверху: Raw EEG Signal** - реальна електрична хвильова форма на частоті 512 Гц. Це те, що вимірює гарнітура - композитний сигнал усіх частот мозкових хвиль.
- **Знизу: Frequency Bands** - п'ять ритмів, виділених гарнітурою: Альфа (зелений), Бета (жовтий), Гамма (червоний), Тета (синій), Дельта (фіолетовий)

Проведіть по будь-якому графіку для прокрутки - обидва залишаються синхронізованими. Масштабування колесом миші або зведенням/розведенням пальців.

## Щоденник (Diary)

Перейдіть на вкладку **Diary** для перегляду минулих сесій (потрібен обраний користувач).

### Список сесій

Верхня половина показує всі сесії поточного користувача, починаючи з найновіших. Кожен запис містить: номер сесії, дату/час, тривалість та середню оцінку шаматхи. Натисніть для вибору.

### Деталі сесії

Нижня половина показує деталі обраної сесії:

- **Статистика** - тривалість, середні значення, час вище порогу, найдовша серія, настрій
- **Нотатки** - текстове поле для роздумів про сесію
- **Теги** - мітки через кому (наприклад, "ранок, спокій, фокус")
- **Настрій** - повзунок від 1 до 5
- **Save Notes** - зберегти нотатки, теги та оцінку настрою

### Графіки сесії

Три вкладки під секцією нотаток:
- **Metrics** - всі обчислені метрики (як на графіку сесії, але для збережених даних)
- **Raw EEG** - синтезована хвильова форма зі збережених потужностей ритмів
- **Frequencies** - діаграма потужності ритмів (Альфа, Бета, Гамма, Тета, Дельта)

Усі три графіки показують маркери (пурпурні вертикальні лінії), якщо вони були поставлені під час сесії. Проведіть для прокрутки, колесо миші/зведення пальців для масштабування.

### Експорт

Натисніть **Export CSV** для збереження даних сесії у файл CSV. Відкриється діалог вибору файлу, де можна обрати папку та ім'я файлу. CSV включає всі сирі потужності ритмів, обчислені метрики, мітки часу та стовпець маркерів (1 = маркер присутній).

### Перейменування / Видалення

- Введіть нове ім'я та натисніть **Rename** для зміни назви сесії
- Натисніть **Delete Session** та підтвердіть для остаточного видалення сесії

## Аналітика (Analytics)

Перейдіть на вкладку **Analytics** для перегляду довгострокових тенденцій.

### Підсумкові картки

Чотири картки зверху показують загальну статистику:
- **Sessions** - загальна кількість сесій
- **Total Min** - загальний час медитації у хвилинах
- **Avg Shamatha** - середня оцінка шаматхи по всіх сесіях
- **Streak** - поточна серія щоденної практики

### Графік тенденцій

Натисніть **Daily**, **Weekly** або **Monthly** для перегляду стовпчикової діаграми середніх оцінок шаматхи за обраний період. Під діаграмою кожен період показує: діапазон дат, кількість сесій, середню шаматху та загальну тривалість.

### Інформація про сховище

Внизу: розмір файлу бази даних, кількість сесій, загальна кількість записів даних та кількість користувачів.

## Поради

- **Почніть з імітованих даних**, щоб ознайомитися з інтерфейсом перед підключенням справжньої гарнітури
- **Встановіть поріг** відповідно до вашого рівня досвіду - початківцям підійде 40-50, досвідченим медитуючим 70-80
- **Використовуйте маркери** для позначення важливих моментів під час практики для подальшого аналізу
- **Переглядайте щоденник** після кожної сесії - записуйте нотатки, поки досвід свіжий
- **Слідкуйте за тенденціями** в аналітиці, щоб бачити ваш прогрес за тижні та місяці
- **Спробуйте власні формули** для експериментів з різними метриками (наприклад, чисте співвідношення альфа/бета)
- **Увімкніть таймер** для стабільної тривалості сесій
- На Android екран залишається увімкненим під час сесій (wake lock)
- Усі налаштування зберігаються для кожного користувача і відновлюються при наступному запуску
